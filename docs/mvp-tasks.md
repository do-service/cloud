# Задачи MVP (фазы 0–1)

**Дата:** 2026-10-22 · **Основа:** [prd.md](prd.md) v0.2, [architecture.md](architecture.md) v0.1

**Оценки:** S — до 1 дня, M — 2–3 дня, L — около недели (один разработчик, full-time). Это порядок величины, а не обязательство. **Итого 71 задача (13 S, 41 M, 17 L) ≈ 200 человеко-дней, около 40 недель одного разработчика**; с двумя (бэкенд + фронтенд) — примерно 5–6 месяцев с учётом критического пути и интеграции.

ID задачи → требование из PRD в скобках. «Зависит» — что должно быть готово раньше.
